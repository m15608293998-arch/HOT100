# HOT100

使用 Go 语言刷 LeetCode 热题 HOT 100 的练习代码仓库。

本仓库记录日常刷题过程中的代码实现与数据结构基础练习，涵盖链表、栈、队列、二叉树等经典数据结构与算法。

## 运行方式

需要安装 Go（建议 1.21+，其中 `0543-二叉树直径` 使用了内置 `max` 函数）。每个目录均为独立的 `main` 包，可直接运行：

```bash
# 在对应题目目录下执行，例如反转链表
cd 链表/0206-反转链表
go run main.go
```
